# 🌦️ SkyCast — Premium Weather Dashboard (PRODIGY_WD_05)

SkyCast is a **premium, MSN-inspired weather dashboard** built with **Vanilla HTML, CSS, and JavaScript**, designed to feel like a paid product rather than a basic weather app. It features a clean **glassmorphism UI**, smooth micro-interactions, a **3D rotating Earth background** powered by **Three.js (WebGL)**, and a premium **multi-theme switcher** (**Ocean / Sunset / Midnight**) with persistence using `localStorage`.

✨ Key Features

City search with Enter key support

Use my location (Geolocation) for instant local weather

Current weather details:

temperature, feels-like

condition text + icon

humidity, wind speed/direction

pressure, visibility, cloud cover

5-day forecast cards (clean horizontal strip)

Hourly “Today’s Trend” temperature timeline (compact bar chart)

Wind direction compass UI

Humidity segmented indicator

Insight card (human-friendly summary based on conditions)

Premium theme switcher:

Ocean → Sunset → Midnight

saved in localStorage

3D globe background for a modern immersive UI

🛠️ Tech Stack

Frontend: HTML, CSS (CSS variables), JavaScript

API: OpenWeatherMap (Current Weather + Forecast)

3D Background: Three.js (WebGL)
